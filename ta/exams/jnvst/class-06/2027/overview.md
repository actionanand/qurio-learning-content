# JNVST தயாரிப்பு மேலோட்டம்

இது தேர்வு தேர்வு, தினசரி திட்டம், வார பார்வை, கட்டத் திட்டம், பாடத்திட்டம், உத்தி, வினாடி வினா மற்றும் முன்னேற்றத்தை சோதிக்க உருவாக்கப்பட்ட **Qurio மாதிரி தயாரிப்பு திட்டம்**.

> Qurio UI/சோதனைக்கான மாதிரி தயாரிப்பு உள்ளடக்கம். உண்மையான தேர்வு திட்டமாக பயன்படுத்துவதற்கு முன் சமீபத்திய அதிகாரப்பூர்வ அறிவிப்பு, பாடத்திட்டம், தகுதி மற்றும் தேதிகளை சரிபார்க்கவும்.

## Qurio திட்ட அம்சங்கள்

- தினசரி தலைப்புகள்
- இடைவெளி மீள்நினைவு
- இணைக்கப்பட்ட படிப்பு குறிப்புகள்
- ஒரே தலைப்பிற்கு பல பயிற்சி வினாடி வினா தொகுப்புகள்
- நேர அட்டவணை பகுதிகள்
- வார பார்வை
- நான்கு தயாரிப்பு கட்டங்கள்
- பயனர் நிலைமையிலிருந்து கணக்கிடப்படும் முன்னேற்றம்
