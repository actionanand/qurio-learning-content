# JNVST மாதிரி பாடத்திட்ட வரைபடம்

இந்த கோப்பு **ஆப் சோதனைக்கான பாடத்திட்ட வரைபடம்**; இது அதிகாரப்பூர்வ அறிவிப்பு அல்ல. Qurio பாடங்களின் கீழ் தேர்வு தயாரிப்பு தலைப்புகளை எவ்வாறு தொகுக்கலாம் என்பதை இது காட்டுகிறது.

| பகுதி | மாதிரி தயாரிப்பு தலைப்புகள் |
|---|---|
| கணிதம் | கணிதச் செயல்கள், பின்னங்கள், வடிவியல், அளவையியல் |
| மொழி | வாசிப்பு, இலக்கணம், சொற்களஞ்சியம், எழுதுதல் |
| நுண்ணறிவு | முறைகள், ஒப்புமை, வகைப்படுத்தல், தர்க்கம் |
| பொதுஅறிவு | இந்தியா, அன்றாட அறிவியல், விளையாட்டு, சூழல் |

## உள்ளடக்க இணைப்பு

பொருத்தமான உள்ளடக்கம் இருந்தால் தேர்வு திட்டம் ஏற்கனவே உள்ள Qurio note/quiz ID-களை மீண்டும் பயன்படுத்த வேண்டும்.
