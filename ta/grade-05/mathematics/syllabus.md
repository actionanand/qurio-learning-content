# கணிதப் பாடத்திட்டம் — 5ஆம் வகுப்பு

   - சமமான பின்னங்கள்
2. **தரவு கையாளுதல்**
   - நிகழ்தகவு
3. **எண்கள்**
   - பகா எண்கள்
4. **எண் செயல்பாடுகள் — கூடுதல் பயிற்சி**

   - கோடுகள் மற்றும் கோணங்கள்
